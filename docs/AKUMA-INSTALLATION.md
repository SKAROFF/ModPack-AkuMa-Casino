# Installation AkuMa 0.2

Installer AKUMA-Launcher-Preview-0.2.0-Windows.exe. Cette préversion Windows x64 utilise Prism officiel pour les comptes Microsoft et le démarrage du jeu. Aucun compte Azure ni identifiant développeur Microsoft n’est demandé.

Cliquer sur Compte Microsoft · Prism. AkuMa télécharge le moteur officiel vérifié. Terminer les éventuelles étapes de bienvenue, puis ouvrir Paramètres → Comptes → Ajouter Microsoft dans Prism. Effectuer soi-même la connexion sur le service Microsoft. Fermer ensuite Prism et revenir dans AkuMa.

Après publication du pack par l’administrateur, cliquer sur Jouer sur AkuMa. Les mises à jour sont appliquées par AkuMa ; Prism installe Java 21, Minecraft 1.21.1 et Fabric 0.19.5, vérifie le compte et prépare la connexion à akuma-casino.mine.fun. Les fenêtres et confirmations nécessaires de Prism ou Minecraft restent visibles.

Les comptes et jetons restent gérés par Prism. AkuMa ne les lit pas et ne les copie pas. Le bouton de déconnexion ouvre Prism pour supprimer le compte dans sa page Comptes.

Le profil est séparé des installations Prism et CurseForge existantes. Ses fichiers se trouvent sous le dossier de données AkuMa, puis prism/instances/akuma/.minecraft. La RAM et la résolution se règlent dans AkuMa ; les autres données personnelles sont conservées. Les anciens dossiers de la préversion 0.1 ne sont pas déplacés ni effacés.

La release publique du pack et le test authentifié dans Prism restent nécessaires avant distribution aux joueurs. Tant que le manifeste signé est absent ou inaccessible, Jouer doit être bloqué. L’installateur de préversion n’a pas de signature Authenticode. Consulter AKUMA-PRISM.md pour les détails et limites.
